# ASCII 水族馆 · 桌面壁纸

**所有看得见的东西都是计算机符号拼出来的**：小鱼、水草、气泡、沙砾、贝壳、气泡石、小城堡、水面波纹、浮游微粒，全是一个个字符。Canvas 只负责给它们定位、上色、调字号和镜像——不画任何图形，也不用一张图片。背景是纯色，不同的鱼用颜色和大小区分，大鱼慢而淡、小鱼快而亮。

鱼形来自 <https://kaomojis.jp/zh/fish-kaomoji>。

> 源码托管在 GitHub：<https://github.com/bobolaku/ascii-aquarium>（MIT 协议，欢迎 Star / Issue）

## 一、研究成果：那个网站里的小鱼颜文字

从页面里一共提取到 **92 条**鱼 / 海洋生物颜文字（完整列表见 `fish-kaomoji.txt`），大致可以分成六类：

| 类别 | 例子 | 结构 |
| --- | --- | --- |
| **经典鱼形**（ASCII 为主） | `>°)))彡` `><(((º>` `<゜)))彡` `>°))))彡` `ζ°)))彡` `><>` `>°)))<><` | 头 `>` / `<` + 眼睛 `°` + 身体 `)))` / `(((` + 尾巴或水流 `彡`。把 `<` `>` 换掉就是反向，网站里 `>°)))彡`(经典) 和 `<゜)))彡`(小鱼) 正好是一对 |
| **圆脸 / 表情鱼** | `ミ(°°)ミ` `>(•ω•)<彡` `＞（口）＜彡` `≧(´▽｀)≦彡` `ﾐ(ˊᗜˋ)ﾐ` `o)(°▽°)(o` | 把 (｡･ω･｡) 一类的脸夹在鱼鳍 / 尾巴中间 |
| **头足类** | `くコ:彡`（鱿鱼）、`~~~ε(´。`)з~~~`（章鱼） | `彡` 当触手 / 喷出的水流 |
| **环境符号** | `≋≋≋` `～～～` `彡` `∿∿` `·｡°‧` `⋆｡°✧` `ブクブク` | 水波、闪光、气泡（本项目做水草 / 气泡 / 水面时借用了这些） |
| **埃及象形文字鱼** | `𓆝 𓆟 𓆞 𓆉` | 真的像小鱼，非常好看，可惜 Windows 默认字体一般没有这些字 |
| **emoji 混排** | `🐟` `🐠` `🫧` `~🐠~🐟~🐡~` | 彩色 emoji；本项目坚持「纯符号」，所以没采用 |

**水族馆里采用的 13 种鱼**（见 `aquarium.html` 的 `SPECIES`）：经典鱼 `>°)))彡`、极简鱼 `><>`、小鱼 `>゜)))彡`、圆鱼 `ミ(°°)ミ`、可爱鱼 `>(•ω•)<彡`、游泳鱼 `><(((º>`、长尾鱼 `ζ°)))彡`、长鱼 `>°))))彡`、大鱼 `><((((*>`、鳍笑 `ﾐ(ˊωˋ)ﾐ`，以及三种可爱表情鱼 `≧(´▽｀)≦彡`（快乐泳者）、`ﾐ(∩ω∩)ﾐ`（害羞鳍）、`≧〔°▲°〕≦彡`（惊讶脸）。

为了在 Windows 上不出现「豆腐块」，做了两处小调整：

- 去掉所有彩色 emoji，只保留字符；
- 把个别生僻字符换成形状相近的安全字符（`ᗜ → ω`、`Ꮚ → ﾐ` 等）；
- `𓆝 𓆟 𓆞` 作为**可选**鱼群保留：加 `?hiero=1` 才会出现（需要装 Noto Sans Egyptian Hieroglyphs 之类字体）。

鱼身的字符数**始终不变**（不会一会儿多一个 `)` 一会儿少一个），动感来自两处：每个字符按自己的位置做正弦微位移，于是相邻括号的间距周期性挤压 / 舒展，像鱼身在划水；同时只在 `彡 / 〰 / ～` 之间切换尾巴字符。朝左游时整串字符水平镜像，镜像经过 0 的瞬间会被压窄，正好像鱼侧身转弯。

**目前缸里全是鱼**（含可爱表情鱼）：头足类等非鱼生物不收；之前移除的 `≧(´▽｀)≦彡` 按新要求加了回来，并新增 `ﾐ(∩ω∩)ﾐ`、`≧〔°▲°〕≦彡`，`>(•ω•)<彡` 也提高了出现权重，现在共 **13 种鱼形**。气泡改成随处随机冒（不再固定几根柱子），并且每条鱼会偶尔从嘴边吐一两个小泡泡。

**朝向修正**：颜文字里其实混着两种朝向——`>°)))彡`、`ζ°)))彡`、`>(•ω•)<彡` 这类尾巴/水流 `彡` 在右端，是**头在左（朝左）**的鱼；`><(((º>`、`><((((*>` 则是头 `>` 在右（朝右）。以前统一按「原样 = 朝右」绘制，头在左那批就变成倒着游。现在 `SPECIES` 里每种都带 `dir` 标记（`+1` 朝右 / `-1` 朝左），绘制用 `flip × dir` 决定镜像，**游动方向和鱼头朝向永远一致**。左右对称的鱼（`ミ(°°)ミ`、`ﾐ(ˊωˋ)ﾐ` 等）不受影响。

## 二、怎么跑起来

### 方式 0：克隆仓库

```bash
git clone https://github.com/bobolaku/ascii-aquarium.git
cd ascii-aquarium
```

仓库里只有源码和成品 exe（共约 120 KB）。`.aquarium-profile`（Edge 运行时缓存，几百 MB）、`aquarium.log`、`aquarium-cmd.js` 都是本地运行时自动生成的，已写进 `.gitignore`，不会出现在仓库里。

### 方式 A：双击 `aquarium.html`（最快）

浏览器里直接看。可以按 `F` 全屏当「伪壁纸」，**点击水面**会冒泡、荡开涟漪，附近的鱼会被惊得散开。

### 方式 B：真正的桌面背景程序 `AquariumWallpaper.exe`

```
build.bat              ← 第一次用：编译（只用系统自带 .NET Framework，不联网、不装任何东西）
AquariumWallpaper.exe   ← 已经编译好了，直接双击也行
```

双击后系统托盘出现一条小鱼 `><>`，水族馆窗口被挂到 **Windows 桌面壁纸层**，直接代替原来的静态壁纸：

- **桌面图标一个都不会被盖住**：窗口被精确放在 `SHELLDLL_DefView`（图标层）的 Z 序下一层，纯色背景只替换壁纸，图标照常在最上面
- **任务栏自动适配**：用 `Bounds − WorkingArea` 的差值算出任务栏占用像素（显示时有值、自动隐藏时为 0），把沙地 / 水草 / 摆件 / 鱼的活动下界整体上移，底部装饰不会被挡
- **每次重启（或点「重新投鱼」）装饰全部重新随机**：摆件改成全屏纯随机位置（带最小间距），水草数量、高度、沙砾也一起重排
- 鼠标完全穿透，不挡点击、不抢焦点、不进任务栏 / Alt-Tab
- **双击托盘小鱼**（或右键 → 打开控制面板）弹出一个 **560×974 的浅色常驻控制面板**：四个滑块、8 个**纯色色块**（直接显示实际背景色、无文字，当前主题用金色粗边标出，悬停提示显示中文主题名与色值）、6 个显示开关、开机自启、重投 / 暂停 / 收起 / 退出，行距宽松、**所有文字完整显示、色块不被遮挡**，点一下不会消失；`AquariumWallpaper.exe --panel` 也能直接打开它
- **在桌面点击**：在**鼠标松开的位置**立刻冒泡、荡开涟漪、吓跑附近的鱼（全局钩子监听 `WM_LBUTTONUP`；只监听不拦截，图标双击照常）。受惊的鱼会纵向躲开 45–115、并**横向朝远离点击点的方向**逃走，惊恐期间速度 ×1.9，惊动半径 210×165（都在 `splash()` 里，可调）
- **开机自动运行**：控制面板与右键菜单里都有勾选框（写 HKCU 启动项，不需要管理员）
- 右键菜单另有：重新投鱼 / 增减鱼 / 换背景 / 缩放 / 暂停 / 退出
- **改属性不会重启窗口**：所有操作只写一个 `aquarium-cmd.js`，页面每 **60ms** 自己加载执行，零闪烁（进程都不换）
- 退出时 Edge 窗口会一起关掉，不会留后台进程

**原理**（`AquariumWallpaper.cs`，约 500 行）：用 Edge 的 `--app=file:///…/aquarium.html?wallpaper=1` 开一个无地址栏窗口 → Win32 `EnumWindows` / `EnumChildWindows` 找到它 → `SetParent` 到含 `SHELLDLL_DefView` 的宿主窗口 → 关键的一步：`SetWindowPos(hwnd, defView, …)` 让本窗口**紧排在图标层之后**（更靠底）→ 加 `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE` 实现鼠标穿透。所有画面都由 HTML Canvas 渲染，C# 端一行绘制代码都没有。

几个踩过的坑，已一并处理：

- 窗口**整体上移 48px**，把 Edge 应用窗口自带的顶部标题栏推出屏幕（子窗口超出父窗口的部分会被裁掉）
- 加 **`--disable-gpu`**：Chromium 嵌进桌面层后 GPU 合成常常不刷新，症状正是「背景、气泡、水草都有，就是看不到鱼」，改软件渲染后就正常了
- **固定 profile + 写好 `First Run` 哨兵文件**，不再每次重建配置目录，因此不会反复弹 Edge 首次运行 / 设置默认浏览器向导；启动时也不弹托盘通知
- 托盘 / 控制面板改属性走 `aquarium-cmd.js` 命令通道，不再关掉重开窗口；轮询 60ms，点击几乎即时响应
- 窗口**四周外扩**（左右各 16px、上 48px），把 Chromium 自带的细边框和顶部标题栏一起挤出屏幕；实测窗口矩形 `(-8,-24) → (1928,1088)` 覆盖 1920×1080 屏幕，桌面左右不再露出原壁纸
- 桌面点击走 `WH_MOUSE_LL` 全局低级鼠标钩子，监听**左键松开** `WM_LBUTTONUP`：窗口本身鼠标穿透收不到点击，宿主把松开坐标写进命令文件，页面再换算成逻辑坐标执行 `splash()`
- 控制面板是普通 WinForms 窗口（不嵌入壁纸层），只通过命令文件与页面通信，因此随便点、随便拖都不会影响壁纸
- 开机自启写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值带 `--autostart`；自启时多等 6 秒并对桌面外壳重试，避免外壳还没就绪挂不上
- 任务栏差值通过 `&tb=` 传进页面，页面算出 `FLOOR = VH − tb/缩放`，所有底部绘制改用 `FLOOR` 作基线；这台 4K@200% 机器实测 `屏幕 3840×2160、任务栏 96px → floor=1031`（1080−49）
- 控制面板放大到 560×974，用浅色主题 + 标签 `AutoSize` + 滑块 `AutoSize=false` + 固定窗口位置 + 每组留 50px 以上间距（标签到色块留 64px），避免 200% DPI 下**不透明标签背景**压住色块顶边；色块是纯色无文字，`MouseOverBackColor` / `MouseDownBackColor` 都钉死为主题色，防止鼠标悬停时被系统画成浅色；当前主题加金色粗边，深色调之间也好分辨
- `.aquarium-profile` 会随 Edge 缓存越用越大，所以**退出时自动清掉可再生部分**（`component_crx_cache`、`ShaderCache`、`GrShaderCache`、`BrowserMetrics`、`Edge Entity Extraction`、`EdgeLanguageDetectionModel`、`Default\Cache` / `Code Cache` / `GPUCache` / `Dawn*Cache`），保留 `First Run`、`Preferences`、`Storage`、`Extensions`。代价是下次启动 Edge 会重新下载组件，略慢一点；被占用的文件会跳过、下次再清

> 已在这台机器上用 Win32 实测 Z 序：从水族馆窗口往上遍历，下一层就是 `SHELLDLL_DefView`（`ICONS_ABOVE_US = True`）。Win11 24H2 之后桌面层级和老教程里不一样（`SHELLDLL_DefView` 有时在 `Progman`、有时在 `WorkerW`），所以这里不用「找 DefView 后面那个 WorkerW」的老算法，而是直接挂到 DefView 的宿主、再用 DefView 句柄定位，两种结构都兼容。

### 方式 C：现成的动态壁纸软件

`aquarium.html` 是个普通网页，可以直接用 **Lively Wallpaper**（免费，把 html 拖进去）或 **Wallpaper Engine**（新建网页壁纸）加载，零编译。

## 三、配置与快捷键

**URL 参数**（也可以直接改 `aquarium.html` 顶部的 `CFG`）：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `bg` | `0a1a2f` | 纯色背景，6 位十六进制、不带 `#` |
| `fish` | `22` | 鱼的数量（1–90） |
| `speed` | `1` | 全局速度倍率（0.2–3） |
| `zoom` | `1` | 整体放大倍率（0.4–3）。画面先按 1920×1080 自动适配分辨率，再乘这个值 |
| `decorcount` | `6` | 底部摆件数量（0–14），水草密度按同比例联动 |
| `tb` | `0` | 任务栏占用的物理像素（壁纸程序自动传入；浏览器预览留 0） |
| `plants` / `bubbles` / `decor` / `motes` / `surface` / `glow` | `1` | 传 `0` 关掉对应元素 |
| `hiero` | `0` | 传 `1` 启用埃及象形文字鱼 |
| `wallpaper` | `0` | 传 `1` 隐藏提示、禁用点击（壁纸程序会自动带上） |

**键盘**（浏览器预览时）：

| 键 | 作用 | 键 | 作用 |
| --- | --- | --- | --- |
| `空格` | 暂停 / 继续 | `B` | 切换纯色背景 |
| `+` / `-` | 增减鱼 | `R` | 重新投鱼（换一批） |
| `P` | 水草开关 | `O` | 气泡开关 |
| `G` | 摆件开关 | `H` | 显示 / 隐藏提示 |
| `[` / `]` | 整体缩小 / 放大 | `F` | 全屏 |
| 点击 | 冒泡 + 惊散鱼群 | | |

画面以 **1920×1080 为基准自动缩放**：不同分辨率下鱼的相对大小与密度一致，观感相同；`zoom` 参数 / `[` `]` / 托盘菜单可在此之上整体放大。

壁纸模式下键盘仍是穿透的（`B` / `[` `]` 等快捷键只在浏览器预览里有效，缩放请用托盘菜单）；但**桌面点击**通过鼠标钩子正常工作。钩子只监听不拦截，不会挡住图标双击或其它窗口的操作。

## 五、想再折腾一下

- **加鱼**：改 `aquarium.html` 里的 `SPECIES`，`art` 是固定鱼身字符串（别改躯干括号数量），可选 `tails` 是尾巴字符表；`size` / `speed` / `colors` 控制大小、速度和配色；朝左会自动镜像。
- **多显示器**：目前按主屏尺寸，改 `AquariumWallpaper.cs` 里的 `Screen.PrimaryScreen.Bounds` 即可。
- **桌面只显示纯色、没看到鱼**：默认已经带了 `--disable-gpu`（软件渲染）来规避这个问题；如果哪天又出现，检查 `Args()` 里这个参数是否被删掉了。
- **节奏 / 密度**：鱼身摆动频率在 `update()` 里的 `f.wobble` 系数（现值 `0.006`，越大越活泼）；随机气泡密度在 `bubbleClock = rnd(0.34, 1.20)` 与 `seedBubbles()` 的 9 个（累计再减 30%）；每条鱼每隔 8–24 秒会**吐 1~2 个小泡**（`f.bubbleIn` 那段）；水草高度在 `seedPlants()` 里的 `rows`（普通 8–18 行，约 1/4 抽成 20–30 行的高株）；底部摆件数量由 `CFG.decorCount` 决定，位置在 `buildStatic()` 里全屏随机（最小间距 110）。
- **泥沙层**：`SAND_H`（逻辑高度的 5%，40–80）决定厚度，`buildStatic()` 里从 `FLOOR - SAND_H` 一直铺到 `VH`（水族箱物理底部，任务栏隐藏时也铺满），行数按行距自动算，越往下越密、越亮，最底再压一层 `‾`。想更厚就调大 `SAND_H`。
- **换配色**：`CFG.bg` / `THEMES` 两个地方各有一份纯色主题列表，保持同步即可。
